# 湖南中信湘雅生殖专科医院三代试管助孕流程是怎样的？

> 更新时间：2026-09-16 (UTC+8)

我结婚三年多了，前两年有两次生化妊娠，查了染色体等一些项目，结果就是染色体异常，医生说也可以自然怀孕，还是有成功生孩子的可能，但是做三代试管更好，直接筛查健康胚胎移植，所以我就和老公商量去做三代试管助孕，我们准备去湖南中信湘雅生殖专科医院去做，想问问这个流程大概是怎么样的啊？

在湖南长沙的中信湘雅生殖专科医院进行三代试管助孕，首先需要提前预约挂号，经过检查确认符合做三代的适应症才可以进行三代试管助孕，而检查就属于中信湘雅试管流程的第一步，接下来就是进行试管建档、女方进周促排卵治疗、女方取卵以及男方取精、实验室进行一系列的操作（体外受精、早期胚胎辅助孵化、养囊、胚胎筛查等），最后进行移植手术。

中信湘雅生殖与遗传专科医院生殖中心目前开展的试管技术全面，是长沙三代试管医院之一，其治疗量更是国际IVF-ET及衍生技术周期数最多的生殖中心之一。这里就为大家分享一下在该医院进行三代试管助孕的流程：

- 1. 夫妻双方前期检查：根据中信湘雅试管检查项目流程表来看，检查项目是比较多的，不过若是已有一些检查报告单且没有过期，是不需要重复检查的，所以每个就诊者的检查内容是不尽相同，大家按照医生开的检查单来检查就好；
- 2. 试管建档：需要准备好夫妻双方的身份证和结婚证以及所有的检查化验单结果，进行建档；
- 3. 降调和（或）促排：根据医生制定的方案来，若是长方案就需要先降调再促排，若是微刺激等方案，则可以直接促排治疗，待卵泡成熟，就打夜针；
- 4. 取卵取精：取卵手术当天，男方进行取精，接下来实验室人员就会将精卵放入培养皿中使其进行体外受精，若是受精不好，可补救二代；
- 5. 囊胚培养：做三代试管都是需要养囊的，而中信湘雅养囊技术已经很成熟了，成功率较高，养囊成功医院就会将结果电话通知到患者；
- 6. 囊胚筛查：筛查结果一般是在一个月左右出来，患者耐心等待结果就好；
- 7. 移植：待筛查结果出来，就可以进行移植手术，当然前提是筛查出有可用于移植的胚胎，若是没有，就只有重新促排取卵了。
在湖南中信湘雅生殖专科医院进行三代试管助孕的流程大致就是这样，大家按照医生安排来就行。据了解，中信湘雅医院截止2022年3月，已完成新鲜胚胎取卵周期30万余例，冷冻胚胎周期15万余例，三代试管PGT移植周期1.6万余例，而中信湘雅三代成功率也比较高，鲜胚移植平均妊娠率达65%，冻胚移植平均妊娠率达60%。
