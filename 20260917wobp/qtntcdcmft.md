# 赵英俊、吴孟达因肝癌去世，悲痛之余我们该如何爱护肝脏？

> 更新时间：2026-09-17 (UTC+8)

2月3日，知名音乐人赵英俊因肝癌不幸去世，享年43岁。

2月27日，著名喜剧演员吴孟达因肝癌离世，享年68岁，让很多网友陷入悲痛之中。

悲痛之余，也让大家再次重视起肝癌这一疾病。吴孟达从发现肝癌到去世，中间只隔了两个月。大多数肝癌患者被发现时已经到了中晚期。对于肝癌，我们该如何早发现、早治疗呢？生活中哪些因素会诱发肝癌？常见肝病有哪些？我们又该如何预防呢？ 

**首先，让我们简单了解一下肝脏——**

肝脏是人体最大的消化器官，通过分泌胆汁帮助消化。

肝脏具有代谢、解毒、造血和强大的免疫功能。

肝脏受损对人体健康的危害极大，但即使肝细胞损坏70%，人也未必会感到任何不适。

**常见肝病**

肝病是指发生在肝脏的病变。包括乙肝、甲肝、丙肝、肝硬化、脂肪化、肝癌、酒精肝等多种肝病。是一种常见的危害性极大的疾病，应以积极预防为主。

据了解，全球约有2.4亿人患有慢性乙肝，约1.5亿人患有慢性丙肝。每年约有一百万人死于与病毒性肝炎相关的疾病，最常见的是肝硬化和肝癌。 比如乙型肝炎，2018年《柳叶刀》发布的报告显示，我国乙肝传染率高达5.1%~10%，约有8000万的病毒携带者，其中2000万为确诊病人；

此外，脂肪肝在我国很常见，在城市人口中可达27％，我国慢性酒精性肝病和非酒精性脂肪肝的平均患病率分别为4.5％和15％。在住院肝病患者中，酒精性肝病患病率从4.2％上升至21.3％。

**哪种肝炎易癌变**

病毒性肝炎是我国肝癌发生的最主要原因。肝癌患者中有80%~90%都是肝炎病毒所导致的。肝炎病毒共有甲、乙、丙、丁、戊五种，其中乙型、丙型最容易造成肝癌。我国肝癌患者中有80%~85%是乙肝造成的。不同病毒引发的肝炎，其传播途径和感染后的临床过程不同。甲肝和戊肝是消化道传播疾病，可以通过污染的手、食物或水传播；乙肝、丙肝和丁肝则主要通过母婴垂直、性和血传播。

摄入过量的酒精会引起肝脏的炎症，造成酒精性肝炎，并引发肝脏的纤维化、硬化，最终诱发肝癌。酒精在肝脏中的代谢产物——乙醛都是世界卫生组织旗下国际癌症研究机构确定的一类致癌物。男士每天摄入酒精达到40克，女士每天达到20克，连续5年，90%~95%会发展为酒精性脂肪肝，40%会发展为酒精性肝炎，2%~10%会发展为肝硬化，最终发展成为肝癌。

肝脏的脂肪超过整个肝脏的5%时，就会变成脂肪性肝炎，过多的脂肪酸氧化会引发炎症，导致肝硬化甚至癌症。

**哪些因素会诱发肝病、肝癌**

1. 蛋白质、B族维生素缺乏引起肝坏死、脂肪变性、纤维化最后癌变。

2. 胱氨酸、维生素E和硒的缺乏引起弥漫肝细胞坏死。 

3. 营养过度导致脂肪肝越来越多。 

4. 黄曲霉菌毒素和亚硝胺引起肝脏急性损伤，甚至发生癌变。

5. 水产品和水污染：甲肝病毒通过污水和粪便污染各种水源，如井水、塘水、河水、自来水和游泳池水等，引起甲肝流行。水产品，如蛤类、牡蛎、泥蚶、蟹等，极易遭受污染。饮用水污染则是戊肝爆发流行的主要传播方式。池塘中生长的蓝绿藻产生的藻类毒素可污染水源，可能与肝癌有关。

6. 饮酒：长期大量饮酒（乙醇摄入量＞80g/d，10年以上），酒精及其代谢产物引起肝脏损害，引发酒精性肝炎、酒精性脂肪肝，继而发展为肝硬化。

**如何爱护肝脏**

**1. 积极锻炼，保持健康体重**

体重过重增加肝脏负担，因此在日常生活，应维持定时定量、并以锻炼体力和耐力为目标的全身性低强度运动，保持健康体魄。

**2. 定期体检，及早发现肝损伤**

健康人群至少每年体检一次。发现肝功异常应及时找肝病专科医生诊治。慢性肝病患者则应在医生的指导下定期随访。 

**3.忌熬夜**

中医认为每天晚上11时至凌晨2时是我们入睡的时候，是肝胆精气血最旺，养肝血的最佳时期。重点在于卧字，只有我们入眠了，肝脏才能更好的工作，如果我们长时间的熬夜，肝脏无法进行自我修复和排毒，也会导致肝细胞损伤肝功能异常，使肝病病情加剧。

**4.少喝酒或者不喝酒**

日常我们喝的酒里，含有酒精，酒精的主要成分就是我们日常说的乙醇。喝进去的乙醇，90%都会在肝脏代谢， 当肝脏开始工作后，乙醇会在肝脏里发生一系列的化学反应，先是变成乙醛，然后又变成乙酸。乙醛的活性非常高，可以与蛋白质结合形成乙醛-蛋白质的结合物，这个结合物会对肝脏造成直接的影响。想要降低酒精对肝脏的影响，日常我们要少喝酒或者不喝酒，即便避免不了的喝酒场景，也应该酒前酒后都做好准备，尽量降低酒精对肝脏的伤害。

**5.注意日常防护，远离感染源**

远离毒品，避免输入受污染血液。切勿共享针具，进行不安全注射；在进行纹身及穿孔时，应确保工具已完成清洁消毒。在进行性行为时，必须做好安全措施，降低经体液的传播风险。

**6.控制体重，防止脂肪性肝病**

随着人们生活水平的提高，肥胖人群越来越多，肥胖人群脂肪肝的发生率显著升高。脂肪肝是指肝细胞内储存了过多的脂肪。部分脂肪肝患者会发生慢性炎症即非酒精性脂肪性肝炎，一旦进入炎症阶段，长期发展也有肝硬化的风险。

**7.及时接种乙肝疫苗**

防治传染病最有效的途径是接种疫苗，乙型肝炎疫苗是全世界范围内迄今为止最成功的疫苗之一，也是人类第一个防癌疫苗。乙肝是可能通过疫苗接种实现全面消除的传染病。及时接种乙肝疫苗，解决检测和治疗覆盖率低的差距，为2030年前实现全球肝炎消除目标而共同努力。
